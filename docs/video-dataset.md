# Dataset vidéo nettoyé

`queryVideoDataset(catalog, { table, columns?, where?, limit?, offset? })` accepte uniquement les sept tables de métadonnées et leurs colonnes autorisées. Les filtres sont des égalités liées par paramètres SQL ; aucune chaîne SQL libre ni mutation n'est acceptée. Maximum : 1000 lignes par page et offset 1000000. Chemins privés, corps, URLs signées, configurations de jobs, erreurs, headers, cookies et références de preuves ne sont pas exposés.

`exportVideoDataset(catalog, { format, output, includeText?, sourceId? })` écrit un fichier neuf JSON, JSONL, SQL ou wiki Markdown. Les exports SQL créent uniquement `curated_dataset_metadata` et `curated_dataset_document` ; ils ne dumpent pas la SQLite protégée. Les assets de la capture restent représentés par leurs métadonnées.

Le texte est opt-in : `includeText: true` extrait les titres, headings, paragraphes et liens HTML ou les sous-titres présents dans les fichiers capturés. Scripts, styles, formulaires, navigation, espaces de compte/authentification, licences et télémétrie JSON restent exclus. Emails, credentials explicites, Bearer/JWT et query strings sont filtrés. Les corps lus sont limités à 2 MiB, les paragraphes à 4096 caractères et un document à 40000 caractères. La provenance expose uniquement sourceId, index, MIME, domaine, chemin sans query, hash du texte et date de génération. Les fichiers bruts ne sont pas synchronisés ni intégrés au corpus.

`createVideoDatasetCache({ sqlitePath, redisURL? })` réutilise `CrawlerCache` et `Bun.RedisClient` derrière une façade `cache.get/set/delete`. Les clés sont hashées ; les valeurs sont nettoyées et les clés de données privées sont refusées. Le cache Redis est configuré seulement avec une URL explicite ; celle-ci n'est jamais retournée. `probe()` exige un vrai `PING`/`PONG`, avec un délai global de 2 secondes par probe/commande, un retry maximum et sans boucle de sommeil. Sans URL, Redis est `disabled`. La SQLite reste le cache local des seules données nettoyées ; les captures et artefacts privés restent séparés.
